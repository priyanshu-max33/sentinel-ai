# Sentinel AI

Prompt-Injection-Resistant AI Agent

## Project
An AI agent that reads emails, webpages and PDFs while treating
external content as untrusted.

## Security Principle
The LLM can propose actions, but independent backend policies
validate and authorize every action.

## Technology
- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: SQLite
- AI: Claude API
